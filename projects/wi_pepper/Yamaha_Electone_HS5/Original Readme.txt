I learn music with a Yamaha Electone HS-5 organ (1987). I sampled the Drum kit of this FM style organ because it’s a nice vintage sound. I give it as freeware : if you like it, just let me know ;). 

The patch Kit include 23 samples and needs 5sc of ram and 1 HD floppy. 
To write it back on floppy, you will need SDisk (included : please read SDISK.DOC).
