# Shared MIDI library approval

Before modifying, adding, deleting, renaming, or generating any file under
`libraries/Midi/`, describe the proposed changes and obtain the user's explicit
approval. Read-only inspection is allowed. A MIDI error report or a general
request to fix a project does not itself authorize shared-library changes.

Once the user approves a specific scope, continue within that scope without
asking again. An explicit request to revert the assistant's changes authorizes
that targeted revert; preserve all other user and project work.

The matching user skill is `bela-midi-library-approval`.
